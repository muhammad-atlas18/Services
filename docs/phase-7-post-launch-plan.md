# Phase 7 — First 30 Days Post-Launch Plan

## Objective

Use real search, engagement and WhatsApp-conversion data to improve qualified Lahore enquiries without publishing unsupported claims, unconfirmed areas or prices.

## Weekly review cadence

| Week | Review | Action |
| --- | --- | --- |
| 1 | Production health, indexability, conversion actions | Fix launch defects; verify sitemap, search visibility, WhatsApp links and form delivery |
| 2 | Landing-page engagement and WhatsApp CTA clicks | Improve CTA placement/copy only where evidence supports it |
| 3 | Search queries, service interest and common enquiry themes | Strengthen useful service content and FAQs; add approved project proof |
| 4 | Enquiry quality, response time and service demand | Create a prioritised optimisation backlog and agree the next release |

## KPI tracker

| KPI | Source | Initial target |
| --- | --- | --- |
| Qualified WhatsApp enquiries by service | CRM or manual enquiry log | Establish baseline first |
| WhatsApp click-through rate | GA4 event data | Compare by page/device; no assumed target |
| Organic impressions and clicks | Google Search Console | Establish baseline first |
| Contact-form completion and delivery success | Analytics + notification log | Confirm zero lost valid leads |
| Response time to first message | Business operations log | Establish baseline first |
| Project/testimonial additions | Content record | Only genuine approved proof |

## Optimisation rules

- Do not change a page solely because of a small data sample.
- Keep the WhatsApp-first journey and no-price policy intact.
- Add location pages only after the area is operationally covered and has unique useful content/proof.
- Do not add ratings, testimonials, project results or warranty claims without evidence and approval.
- Record the reason, expected outcome and measurement method for every content or UX change.

## First content backlog

1. Add six approved project case studies with service, non-sensitive area, challenge and completed scope.
2. Add verified testimonials with permission.
3. Expand service FAQs from recurring real customer questions.
4. Add supported solar/electrical/AC equipment information after business confirmation.
5. Create only confirmed-area content pages, beginning with the service areas producing real enquiries.

## Data needed after deployment

- Production URL and deployment date
- GA4 property/event access
- Search Console property access
- Enquiry/response-time log or CRM export
- Owner-approved monthly project/testimonial additions
